Como executar
-------------
Requer Python 3.10 ou superior (precisa de match-case).
Nao tem dependencia externa - usa apenas a biblioteca padrao
do Python (os, math, random, datetime).

Para rodar no terminal:

    python agrolunar.py

O menu principal aparece com 6 opcoes mais a opcao de sair (0).
Apos cada execucao o programa volta pro menu inicial.
